## ML Fundamentals

### ML vs. AI vs. Gen AI

```
AI (Artificial Intelligence)
└─ Broad: Any system that mimics intelligence
   ├─ Rules-based systems
   ├─ Machine Learning
   │  ├─ Supervised (Classification, Regression)
   │  ├─ Unsupervised (Clustering, Dimensionality Reduction)
   │  └─ Reinforcement Learning
   └─ Deep Learning
      ├─ CNNs (Images)
      ├─ RNNs (Sequences)
      ├─ Transformers (NLP, Gen AI)
      └─ Gen AI (Generative Models)

Gen AI (Generative AI)
└─ Specific: Models that generate new content
   ├─ LLMs (Text generation)
   ├─ Diffusion models (Image generation)
   ├─ Multimodal models (Text + Images)
   └─ Video generation
```

## Large Language Models (LLMs)

### LLM Fundamentals

```
LLM (Large Language Model)
├─ Definition: Neural network trained on massive text data
│  (100B+ parameters, trillions of tokens)
│
├─ Training Process:
│  1. Pretraining: Predict next word on huge corpus
│  2. Fine-tuning: Adapt to specific tasks
│  3. RLHF: Reinforcement Learning from Human Feedback
│
├─ How it works:
│  1. Tokenization: "Hello world" → ["Hello", "world"]
│  2. Embedding: Tokens → vectors
│  3. Transformer: Process in parallel, self-attention
│  4. Generation: Predict next token iteratively
│
└─ Popular LLMs:
   ├─ Gemini (Google)
   ├─ GPT-4 (OpenAI)
   ├─ Claude (Anthropic)
   ├─ LLaMA (Meta, open-source)
   └─ Mistral (open-source)
```

## Embeddings & Vector Databases

### Text Embeddings

```
Embedding: Convert text to fixed-size vector
"The quick brown fox" → [0.23, -0.45, 0.89, ..., 0.12]
                        ↑ Dense vector (1024-3072 dimensions)

Why embeddings?
├─ Semantic similarity (similar text → similar vectors)
├─ Numerical representation (can do math on text)
├─ Efficient search (vector search faster than text search)
└─ Transfer learning (reuse pre-trained embeddings)
```

### Vertex AI Text Embeddings

```python
from vertexai.language_models import TextEmbeddingModel

model = TextEmbeddingModel.from_pretrained(
    "textembedding-gecko@003"
)

# Get embedding for text
embeddings = model.get_embeddings([
    "Customer is very satisfied",
    "Customer is happy with product",
    "Customer wants a refund"
])

for embedding in embeddings:
    vector = embedding.values  # 768 dimensions
    print(f"Vector shape: {len(vector)}")

# Use for semantic similarity search
from sklearn.metrics.pairwise import cosine_similarity
import numpy as np

vectors = [e.values for e in embeddings]
similarity = cosine_similarity([vectors[0]], vectors[1:])[0]
print(f"Similarity between first two: {similarity[0]:.3f}")
# Output: 0.891 (high similarity, same meaning)
```

### Vector Database Integration

```python
# Chroma: Simple vector database for embeddings
from chromadb.client import Client
from vertexai.language_models import TextEmbeddingModel

# Initialize
client = Client()
collection = client.create_collection(name="research_papers")

# Add embeddings
embedding_model = TextEmbeddingModel.from_pretrained(
    "textembedding-gecko@003"
)

papers = [
    {"id": "1", "text": "Deep learning for time series..."},
    {"id": "2", "text": "Neural networks for classification..."},
    {"id": "3", "text": "Transformer models for NLP..."},
]

for paper in papers:
    embeddings = embedding_model.get_embeddings([paper["text"]])
    vector = embeddings[0].values
    
    collection.add(
        ids=[paper["id"]],
        embeddings=[vector],
        metadatas=[{"source": paper["text"][:100]}],
        documents=[paper["text"]]
    )

# Semantic search
query = "machine learning for sequential data"
query_embedding = embedding_model.get_embeddings([query])[0].values

results = collection.query(
    query_embeddings=[query_embedding],
    n_results=3
)

print("Top 3 related papers:")
for result in results['documents'][0]:
    print(f"- {result[:80]}...")
```

## Retrieval-Augmented Generation (RAG)

### RAG Architecture

```
RAG: Combine retrieval + generation for better answers

WITHOUT RAG:
User Question → LLM → Generated Answer
(Limited by training data, can hallucinate)

WITH RAG:
User Question → Retrieve relevant documents → 
  Augment prompt with documents → LLM → Better answer
(Grounded in real data, verifiable sources)

Use Cases:
├─ Customer support (search knowledge base)
├─ Document Q&A (search internal documents)
├─ Research (search published papers)
├─ Code assistance (search code repositories)
└─ Legal (search precedents)
```

### Building a RAG System

```python
from vertexai.generative_models import GenerativeModel, Content
from vertexai.language_models import TextEmbeddingModel
import chromadb

class RAGSystem:
    def __init__(self):
        self.embedding_model = TextEmbeddingModel.from_pretrained(
            "textembedding-gecko@003"
        )
        self.llm = GenerativeModel("gemini-1.5-pro")
        self.vector_db = chromadb.Client()
        self.collection = self.vector_db.create_collection(
            name="documents"
        )
    
    def ingest_documents(self, documents: list[dict]):
        """Add documents to vector database"""
        for doc in documents:
            # Get embedding
            embedding = self.embedding_model.get_embeddings(
                [doc["text"]]
            )[0].values
            
            # Store in vector database
            self.collection.add(
                ids=[doc["id"]],
                embeddings=[embedding],
                documents=[doc["text"]],
                metadatas=[{"source": doc.get("source", "")}]
            )
    
    def retrieve_context(self, query: str, top_k: int = 3) -> str:
        """Retrieve relevant documents for a query"""
        # Embed query
        query_embedding = self.embedding_model.get_embeddings(
            [query]
        )[0].values
        
        # Search vector database
        results = self.collection.query(
            query_embeddings=[query_embedding],
            n_results=top_k
        )
        
        # Format as context
        context = "\n".join([
            f"Document {i+1}:\n{doc}"
            for i, doc in enumerate(results['documents'][0])
        ])
        
        return context
    
    def answer_question(self, question: str) -> str:
        """Answer question using RAG"""
        # 1. Retrieve relevant documents
        context = self.retrieve_context(question)
        
        # 2. Augment prompt with context
        prompt = f"""
        Based on the following documents, answer the question.
        
        Documents:
        {context}
        
        Question: {question}
        
        Answer:
        """
        
        # 3. Generate answer
        response = self.llm.generate_content(prompt)
        
        return response.text

# Usage
rag = RAGSystem()

# Load your documents
documents = [
    {
        "id": "1",
        "text": "Accenture's revenue in 2023 was $64.1 billion...",
        "source": "Annual Report 2023"
    },
    {
        "id": "2",
        "text": "Cloud services contributed 45% to total revenue...",
        "source": "Investor Presentation 2023"
    },
    # ... more documents
]

rag.ingest_documents(documents)

# Answer questions
question = "What was Accenture's 2023 revenue?"
answer = rag.answer_question(question)
print(answer)
# Output: "Accenture's revenue in 2023 was $64.1 billion... (from Annual Report 2023)"
```

## Research Platform Integration

### AI-Powered Research Assistant

```python
from vertexai.generative_models import GenerativeModel
import json

class ResearchAssistant:
    """AI assistant for research platform"""
    
    def __init__(self):
        self.model = GenerativeModel("gemini-1.5-pro")
        self.research_context = {}
    
    def suggest_hypotheses(self, research_question: str) -> list:
        """Generate hypotheses using AI"""
        response = self.model.generate_content(f"""
        Research question: {research_question}
        
        Generate 5 testable hypotheses:
        1. 
        2. 
        3. 
        4. 
        5. 
        
        For each, provide:
        - Hypothesis statement
        - Expected outcome
        - Measurement method
        - Difficulty (1-10)
        """)
        
        return response.text
    
    def design_experiment(self, hypothesis: str) -> dict:
        """Design experiment methodology"""
        response = self.model.generate_content(f"""
        Hypothesis: {hypothesis}
        
        Design an experiment to test this:
        1. Methodology
        2. Sample size calculation
        3. Duration
        4. Metrics
        5. Potential biases
        6. Controls
        
        Format as JSON.
        """)
        
        return json.loads(response.text)
    
    def analyze_results(self, results_summary: str) -> str:
        """Interpret experiment results"""
        response = self.model.generate_content(f"""
        Experiment results:
        {results_summary}
        
        Provide:
        1. Statistical significance assessment
        2. Practical significance
        3. Limitations
        4. Next steps
        5. Implications for research
        """)
        
        return response.text

# Usage
assistant = ResearchAssistant()

# Step 1: Generate hypotheses
hypotheses = assistant.suggest_hypotheses(
    "How does prompt engineering affect LLM accuracy?"
)
print("Generated Hypotheses:\n", hypotheses)

# Step 2: Design experiment
design = assistant.design_experiment(
    "Detailed prompts improve LLM accuracy by 15%"
)
print("Experiment Design:\n", json.dumps(design, indent=2))

# Step 3: Analyze results
analysis = assistant.analyze_results("""
Test group (detailed prompts): 87% accuracy
Control group (simple prompts): 74% accuracy
Sample size: 500 questions each
P-value: 0.001
""")
print("Analysis:\n", analysis)
```

## Interview Questions

### Q1: "Explain LLMs. How would you use in research platform?"

**Answer:**
- LLMs are neural networks trained on massive text data
- Can generate text, summarize, translate, answer questions
- For research: Auto-generate hypotheses, analyze results, suggest next steps
- Integration: RAG system searching published papers

### Q2: "Design AI assistant for experiment analysis."

**Answer:**
1. **Input**: Experiment results (metrics, statistical tests)
2. **Processing**: LLM interprets results in context
3. **Output**: Insights, recommendations, next steps
4. **Implementation**: Vertex AI + RAG (search prior work)

### Q3: "When would you use embeddings over semantic search?"

**Answer:**
- Embeddings: Convert text to vectors for similarity
- Use when: Need semantic understanding, clustering, or nearest neighbor search
- Example: Find similar research papers
- Alternative: Keyword search (exact match, less semantic)

### Q4: "Build RAG system for research knowledge base."

**Answer:**
1. Ingest papers into vector DB (embeddings)
2. User asks question
3. Retrieve relevant papers (semantic search)
4. Augment LLM prompt with papers
5. Generate answer grounded in sources
6. Return with citations
