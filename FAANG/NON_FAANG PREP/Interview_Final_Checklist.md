## Daily Practice Routine

```

Minutes 70-120: Review
- Analyze solution
- Compare with optimal
- Understand edge cases
- Document learnings

- Practice communication
- Discuss tradeoffs
```

## Interview Day Protocol

### 5 Minutes Before

**Mental Prep:**
- "I prepared well for this"
- "I can think through problems"
- "It's OK to take time and ask questions"
- "Communicate clearly"

### During Interview

**Best Practices:**
1. **Listen carefully** - Don't interrupt
2. **Ask clarifying questions** - Takes 5% of time
3. **Think out loud** - Show your process
4. **Code clearly** - Good variable names
5. **Test thoroughly** - Use examples
6. **Optimize thoughtfully** - After correct answer
7. **Discuss tradeoffs** - Show system thinking
8. **Be humble** - Learn from feedback

**Red Flags to Avoid:**
- ❌ Jumping to code immediately
- ❌ Not handling edge cases
- ❌ Ignoring complexity analysis
- ❌ Not testing code
- ❌ Defensive when questioned
- ❌ Talking too much without thinking
