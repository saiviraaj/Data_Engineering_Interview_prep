## 💡 How to Practice Effectively

### 1. **Write Every Query**
Don't just read! Actually write and execute every query in a real database.

**Setup Options:**
- **PostgreSQL** (recommended for learning)
- **MySQL** (widely used in industry)
- **SQLite** (lightweight, no installation)
- **Online:** SQLFiddle, DB Fiddle, or SQL Playground

### 2. **Use the Database Schema**
Each set includes a complete schema. Set it up locally:

```sql
-- Run the schema creation scripts provided in each set
-- Then populate with sample data
```

### 3. **Don't Peek at Solutions**
1. Read the question
2. Try solving it yourself (10-15 minutes)
3. If stuck, review concepts from the relevant module
4. Only then look at the solution
5. Compare your solution to the provided one

### 4. **Understand, Don't Memorize**
- Focus on WHY the solution works
- Understand the query execution order
- Learn the edge cases and gotchas

### 5. **Track Your Progress**
Create a spreadsheet:
- Question number
- Difficulty
- Got it right? (Yes/No/Partial)
- Time taken
- Date attempted
- Notes

### 6. **Simulate Interview Conditions**
After completing each set:
- Pick 10 random questions
- Time yourself: 5-7 minutes per question
- Write queries without looking at notes
- Score yourself honestly

## 🎯 Difficulty Ratings Explained

### Easy ⭐
- 1-2 concepts per question
- Straightforward syntax
- Minimal nested logic
- Can be solved in 2-5 minutes
- **Target:** 90%+ accuracy

### Medium ⭐⭐
- 2-4 concepts combined
- Multiple clauses (WHERE + GROUP BY + HAVING)
- Some nested logic
- Can be solved in 5-10 minutes
- **Target:** 70-80% accuracy

### Hard ⭐⭐⭐
- 4+ concepts combined
- Complex nested logic
- Multiple JOINs or subqueries
- Window functions with frames
- Can take 10-20 minutes
- **Target:** 50-60% accuracy initially, 80%+ after practice
