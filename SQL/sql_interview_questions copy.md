# SQL Interview Questions (Practice Set)

This document contains **practice SQL questions categorized by
difficulty**.

------------------------------------------------------------------------

# Easy Questions

1.  Find all employees working in the Engineering department.
2.  Find total order amount per customer.
3.  Find number of orders per day.
4.  Find highest salary in the company.
5.  Find customers with no orders.
6.  Count number of employees per department.
7.  Find minimum and maximum order amount.
8.  Find number of products sold per category.
9.  Find employees hired in the last year.
10. Find customers who placed orders today.

------------------------------------------------------------------------

# Medium Questions

1.  Find employees earning above company average salary.
2.  Find highest salary per department.
3.  Find latest order per customer.
4.  Find customers who placed more than 3 orders.
5.  Find second highest salary.
6.  Rank customers by total spending.
7.  Find top 3 highest paid employees per department.
8.  Calculate running revenue by date.
9.  Calculate 7-day moving average sales.
10. Find percentage contribution of each product to total sales.

------------------------------------------------------------------------

# Advanced Questions

1.  Find customers with orders on 3 consecutive days.
2.  Find longest login streak per user.
3.  Detect duplicate records and keep latest.
4.  Find median order value.
5.  Find users who increased spending month-over-month.
6.  Detect session boundaries using inactivity threshold.
7.  Identify customers with declining revenue for 3 months.
8.  Find gaps in order dates.
9.  Calculate cohort retention.
10. Build rolling monthly revenue.

------------------------------------------------------------------------

# Pattern Mapping

  Problem Type        Pattern
  ------------------- ----------------
  Latest record       ROW_NUMBER
  Ranking             DENSE_RANK
  Running totals      Window SUM
  Moving averages     Window AVG
  Streak detection    Gaps & Islands
  Deduplication       ROW_NUMBER
  Session detection   LAG
  Missing records     Anti Join
